# MiniBrands Design System Skill

## When this skill applies
Load this skill any time you are:
- Writing or editing any TSX/CSS/Tailwind class in this project
- Creating or refining components under `src/components/` or `src/app/`
- Adjusting spacing, typography, colors, animations, or layout
- Reviewing whether a UI change is consistent with the design language
- Planning a new feature's frontend presentation

## Core Constraint
> **Do NOT modify:** Backend · APIs · Database · Prisma · Authentication · Server Actions · Routes · Business Logic · State Management · Data Flow · Existing Functional Components.
> **Only modify:** UI · UX · CSS · Tailwind · Layout · Typography · Spacing · Colors · Animations · Responsive Design.

See [DESIGN_SPEC.md](./DESIGN_SPEC.md) for the complete specification.
